# AVR Tester v2

Next-generation Raspberry Pi based hardware for testing against AVR
microcontrollers. Successor to the v1 [AVR Test HAT](https://github.com/TomSawyerLabs/avr-test-hat)
(Altium design, local checkout at `..\avr-test-hat`).

Two planned variants sharing one GPIO map:

- **CM4/CM5 carrier board** (primary): native USB connections to the device under test.
- **Pi HAT**: for standard 40-pin Raspberry Pi boards (B form factor).

Designed in KiCad. Every part carries an LCSC part number and is chosen to be
in stock, so boards can be ordered fully assembled from JLCPCB.
